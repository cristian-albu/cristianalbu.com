# Delete Prime Elements

## Statement
Given a vector of `n` natural numbers, delete all elements from the vector that are prime numbers.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers, separated by spaces, representing the elements of the vector.

## Output
The program prints, separated by spaces, the elements of the vector obtained by deleting the prime elements.

## Constraints
- `0 < n ≤ 1000`
- The elements of the vector will be less than `2^30`

## Example
**Input**
```
5
7 8 9 17 1
```

**Output**
```
8 9 1
```
