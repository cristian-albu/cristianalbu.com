# Duplicate Minimum Value Occurrences

## Statement
Given a vector of `n` natural numbers, transform the vector by duplicating every occurrence of the minimum value.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers, separated by spaces, representing the elements of the vector.

## Output
The program prints, separated by spaces, the elements of the vector obtained after the duplication.

## Constraints
- `0 < n ≤ 50`
- The elements of the vector will be less than `2^30`

## Example
**Input**
```
7
7 9 4 2 1 6 1
```

**Output**
```
7 9 4 2 1 1 6 1 1
```
