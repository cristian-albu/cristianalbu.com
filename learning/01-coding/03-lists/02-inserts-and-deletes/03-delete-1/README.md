# Delete Even Elements

## Statement
Given a vector of `n` natural numbers, delete all the even elements from the vector.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers, separated by spaces, representing the elements of the vector.

## Output
The program prints, separated by spaces, the elements of the vector obtained by deleting the even elements.

## Constraints
- `0 < n ≤ 1000`
- The elements of the vector will be less than `2^30`

## Example
**Input**
```
7
7 9 4 2 1 6 5
```

**Output**
```
7 9 1 5
```
