# Check if All Elements Are Equal

## Statement
Given a vector of `n` natural numbers, check whether all elements of the vector are equal.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers representing the elements of the vector.

## Output
The program prints `YES` if all elements of the vector are equal, or `NO` otherwise.

## Constraints
- `1 ≤ n ≤ 500`
- Each element of the vector has at most four digits

## Example
**Input**
```
7
6 6 6 6 4 6 6
```

**Output**
```
NO
```
