# Check if Prime Elements Exist

## Statement
Given a sequence of `n` natural numbers, check whether the sequence contains any prime elements.

## Input
The program reads the number `n` from standard input, followed by the `n` elements of the sequence.

## Output
The program prints `YES` if the sequence contains prime elements, or `NO` otherwise.

## Constraints
- `1 ≤ n ≤ 200`
- The elements of the sequence will be less than `1,000,000,000`

## Example
**Input**
```
5
21 8 6 10 8
```

**Output**
```
NO
```
