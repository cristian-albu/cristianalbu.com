# Check if All Elements Are Even

## Statement
Given a sequence of `n` natural numbers, check whether all elements of the sequence are even.

## Input
The program reads the number `n` from standard input, followed by the `n` elements of the sequence, separated by spaces.

## Output
The program prints `YES` if all elements of the sequence are even, or `NO` otherwise.

## Constraints
- `1 ≤ n ≤ 100`
- The elements of the sequence will be less than `10000`

## Example
**Input**
```
5
2 8 6 10 8
```

**Output**
```
YES
```
