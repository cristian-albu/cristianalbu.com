# Check if Elements Are Sorted Ascending

## Statement
Given a vector of `n` natural numbers, check whether its elements are sorted in ascending order.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers representing the elements of the vector.

## Output
The program prints `YES` if the elements of the vector are sorted in ascending order, or `NO` otherwise.

## Constraints
- `1 ≤ n ≤ 500`
- Each element of the vector has at most four digits

## Example
**Input**
```
7
4 5 7 9 9 10 12
```

**Output**
```
YES
```
