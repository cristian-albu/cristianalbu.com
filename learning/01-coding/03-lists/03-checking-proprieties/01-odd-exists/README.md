# Check if Odd Elements Exist

## Statement
Given a sequence of `n` natural numbers, check whether the sequence contains any odd elements.

## Input
The program reads the number `n` from standard input, followed by the `n` elements of the sequence, separated by spaces.

## Output
The program prints `YES` if the sequence contains odd elements, or `NO` otherwise.

## Constraints
- `1 ≤ n ≤ 100`
- The elements of the sequence will be less than `10000`

## Example
**Input**
```
5
2 8 6 10 8
```

**Output**
```
NO
```
