# Parity Difference

## Statement
Given a sequence of `n` natural numbers, determine the absolute difference between the number of even values and the number of odd values in the sequence.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers representing the elements of the sequence.

## Output
The program prints the number `C`, representing the requested value.

## Constraints
- `1 ≤ n ≤ 1000`
- The `n` numbers read will be less than `1,000,000,000`

## Example
**Input**
```
5
15 245 28 33 11
```

**Output**
```
3
```

**Explanation**
There are 4 odd numbers and 1 even number in the sequence, so the difference is 3.
