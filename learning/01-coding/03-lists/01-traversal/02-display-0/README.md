# Multiples of the Last Element

## Statement
Given a vector of `n` natural numbers, display the elements of the vector that are multiples of its last element.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers representing the elements of the vector.

## Output
The program prints the requested elements, separated by exactly one space, in the order they appear in the vector.

## Constraints
- `1 ≤ n ≤ 1000`
- The elements of the vector will be less than `1,000,000`
- The last element of the vector is non-zero

## Example
**Input**
```
5
7 4 9 6 2
```

**Output**
```
4 6 2
```
