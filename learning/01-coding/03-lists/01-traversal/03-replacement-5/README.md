# Replace Prime Elements with Zero

## Statement
Given a vector of `n` natural numbers, replace every prime element in the vector with `0`, then display the vector.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers representing the elements of the vector.

## Output
The program prints the elements of the vector after the replacement.

## Constraints
- `1 ≤ n ≤ 1000`
- The elements of the vector will be less than `1,000,000`

## Example
**Input**
```
5
7 4 9 6 2
```

**Output**
```
0 4 9 6 0
```
