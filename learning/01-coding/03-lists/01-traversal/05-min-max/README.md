# Minimum and Maximum

## Statement
Read `n`, followed by `n` natural numbers representing the elements of a vector. Compute the minimum value `min` and the maximum value `max` among the elements of the vector.

## Input
The program reads the number `n` from standard input, followed by `n` natural numbers representing the elements of the vector.

## Output
The program prints the two numbers `min` and `max`, separated by a single space.

## Constraints
- `0 < n < 1000`
- The elements of the vector will be less than `1,000,000`

## Example
**Input**
```
5
8 2 9 4 5
```

**Output**
```
2 9
```

**Explanation**
The vector contains 5 elements. The maximum value is 9, and the minimum value is 2.
