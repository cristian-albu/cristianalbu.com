# Divisors Sum

### Requirement

A natural number `n` is read. Determine the sum of its divisors.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program displays on the screen the number `S`, representing the sum of the divisors of `n`.

### Restrictions and specifications

- 0 < n ≤ 1,000,000,000

### Example:

"Input"

```
6
```

"Output"

```
12
```

### Explanation

The divisors of `6` are `1`, `2`, `3`, `6`. Their sum is `12`.
