# SumMaxMin

### Requirement

`n` natural numbers are given. Calculate the sum between the largest and the smallest given number.

### Input data

The program reads the number `n` from the keyboard, and then `n` natural numbers, separated by spaces.

### Output data

The program displays on the screen the number `S`, representing the sum between the largest and the smallest given number.

### Restrictions and specifications

- 1 ≤ n ≤ 100
- the `n` read numbers will have at most 6 digits

### Example:

"Input data"

```
5
7 2 8 4 8
```

"Output data"

```
10
```

### Explanation

8 + 2 = 10.
