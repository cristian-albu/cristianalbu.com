# prefix_sum

### Requirement

Write a program that reads a non-zero natural number `n` and calculates the sum `S` of all distinct numbers that are prefixes of `n`.

### Input data

The program reads the number `n` from the keyboard, with the meaning given in the statement.

### Output data

The program will display on the screen the number `S`.

### Restrictions and specifications

- 1 ≤ n ≤ 2,000,000,000

### Example:

"Input"

```
12345
```

"Output"

```
13715
```

### Explanation

The number `n=12345` was read and the calculated sum is `S=13715` (`=1+12+123+1234+12345`).
