# EvenIntervalDivisors

### Requirement

Two natural numbers `a` and `b` are read. Determine the smallest and the largest number in the interval `[a, b]` with the maximum number of even divisors, and the maximum number of even divisors.

### Input data

The program reads from the keyboard the numbers `a` `b`.

### Output data

The program displays on the screen the numbers `NRD MIN MAX`, separated by exactly one space, representing the maximum number of even divisors of the numbers in `[a, b]`, the smallest and respectively the largest number in the interval with the maximum number of even divisors.

### Restrictions and specifications

- 0 < a < b < 1,000,000,000
- b-a ≤ 1000

### Example:

"Input"

```
10 20
```

"Output"

```
4 12 20
```

### Explanation

The maximum number of even divisors for the numbers in the interval `[10, 20]` is `4`. The numbers in the interval with `4` even divisors are `12`, `16` and `20`.
