# Fibonacci

Consider the Fibonacci sequence, defined as follows: `f1=1`, `f2=1`, `fn=fn-1+fn-2`, if `n>2`.

### Requirement

A natural number `n` is given. Display in ascending order, the first `n` terms of the Fibonacci sequence.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program displays on the screen the first `n` terms of the Fibonacci sequence, in ascending order, separated by a space.

### Restrictions and specifications

- 1 ≤ n ≤ 40

### Example:

"Input data"

```
5
```

"Output data"

```
1 1 2 3 5
```
