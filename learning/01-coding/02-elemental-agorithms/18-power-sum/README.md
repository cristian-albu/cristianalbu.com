# Power Sum

### Requirement

A natural number `n` is given. Decompose the number `n` as a sum of powers of `2`.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program will display on the screen, in ascending order, separated by a space, the powers of `2` whose sum is `n`.

### Restrictions and specifications

- 1 ≤ n < 2^31

### Example:

"Input"

```
43
```

"Output"

```
1 2 8 32
```
