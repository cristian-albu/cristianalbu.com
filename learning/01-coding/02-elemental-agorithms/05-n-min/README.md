# n_min

### Requirement

`n` integers are given. Calculate the smallest of the given `n` numbers.

### Input data

The program reads the number `n` from the keyboard, and then `n` integers, separated by spaces.

### Output data

The program displays on the screen the number `MIN`, representing the smallest of the given `n` numbers.

### Restrictions and specifications

- 1 ≤ n ≤ 1000
- the `n` read numbers will have at most 9 digits

### Example:

"Input data"

```
7 6 9 6 8
```

"Output data"

```
6
```
