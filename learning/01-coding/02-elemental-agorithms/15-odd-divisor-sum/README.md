# Odd Divisor Sum

### Requirement

A natural number `n` is read. Determine the sum of its odd divisors.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program displays on the screen the number `S`, representing the sum of the odd divisors of `n`.

### Restrictions and specifications

- 0 < n < 1,000,000,000

### Example:

"Input"

```
30
```

"Output"

```
24
```

### Explanation

The odd divisors of `30` are `1`, `3`, `5` and `15`. Their sum is `24`.
