### Requirement

Write a program that reads the natural number $n$ and calculates the sum $S = 2 + 4 + \dots + (2n)$.

### Input Data

The program reads the number $n$ from the keyboard.

### Output Data

The program displays on the first line of the screen the message `Sum is S`, where $S$ represents the calculated sum.

### Constraints and Clarifications

$0 < n \le 10000$

### Example

```
48

Sum is 2352
```
