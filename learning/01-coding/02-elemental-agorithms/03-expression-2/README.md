# Expression2

### Requirement

Write a program that reads the natural number `n` and determines the sum `S=1*2+2*3+3*4+...+n*(n+1)`.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program displays on the screen the message `The result is S`, where `S` represents the calculated value.

### Restrictions and specifications

- 0 < n ≤ 100

### Example:

"Input"

```
4
```

"Output"

```
The result is 40
```
