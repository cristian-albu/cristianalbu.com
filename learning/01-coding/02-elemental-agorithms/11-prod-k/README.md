# Prod K

### Requirement

Write a program that reads a natural number `n` and a digit `k`. The program will calculate the product `P` of the digits of `n` different from the digit `k`.

### Input data

The program reads from the keyboard the numbers `n` `k`.

### Output data

The program will display on the screen the number `P`, with the meaning given in the statement. If `n` does not contain digits different from `k`, the program will display the value `0`.

### Restrictions and specifications

- 1 ≤ n ≤ 2,000,000,000

### Example:

"Input"

```
123242 2
```

"Output"

```
12
```

### Explanation

The number `n=123242` was read and the displayed product is `P=12` (`=1*3*4`).
