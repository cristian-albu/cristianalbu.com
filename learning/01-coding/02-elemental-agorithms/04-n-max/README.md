# n_max

### Requirement

`n` integers are given. Calculate the largest of the given `n` numbers.

### Input data

The program reads the number `n` from the keyboard, and then `n` integers, separated by spaces.

### Output data

The program displays on the screen the number `MAX`, representing the largest of the given `n` numbers.

### Restrictions and specifications

- 1 ≤ n ≤ 1000
- the `n` read numbers will have at most 9 digits

### Example:

"Input data"

```
5
7 6 9 6 8
```

"Output data"

```
9
```
