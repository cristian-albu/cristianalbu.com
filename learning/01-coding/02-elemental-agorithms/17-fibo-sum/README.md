# FiboSum

Consider the Fibonacci sequence, defined as follows: `f1=1`, `f2=1`, `fn=fn-1+fn-2`, if `n>2`.

### Requirement

A natural number `n` is given. Decompose it into a sum with the minimum number of terms from the Fibonacci sequence.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program displays on the screen, separated by a space, the terms of the decomposition, in descending order.

### Restrictions and specifications

- 1 ≤ n ≤ 1,000,000,000

### Example:

"Input data"

```
30
```

"Output data"

```
21 8 1
```
