# Sum37

A non-zero natural number `n` is given. Calculate the sum of the digits of `n` that are greater than or equal to `3` and less than or equal to `7`.

### Input data

The program reads the number `n` from the keyboard.

### Output data

The program will display on the screen the number `S`, representing the sum of the digits of `n` that are greater than or equal to `3` and less than or equal to `7`.

### Restrictions and specifications

- 1 ≤ n ≤ 2,000,000,000

### Example 1:

"Input"

```
3590
```

"Output"

```
8
```

### Explanation

The digits of `n` in the interval `[3,7]` are `3` and `5`, and their sum is `8`.

### Example 2:

"Input"

```
144620
```

"Output"

```
14
```

### Explanation

4 + 4 + 6 = 14

### Example 3:

"Input"

```
2021
```

"Output"

```
0
```

### Explanation

There are no digits in the interval `[3,7]`, so the sum is `0`.
