# OddDigitsProduct

### Requirement

Write a program that determines the product of the odd digits of a natural number read from the keyboard.

### Input data

The program will read a natural number from the keyboard.

### Output data

The program will display on the screen the product of the odd digits of the read number.

### Restrictions and specifications

- the read number will be less than 2^31
- if the number does not contain odd digits then the value -1 will be displayed

### Example:

"Input"

```
2705
```

"Output"

```
35
```
