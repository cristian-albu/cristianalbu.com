# Max Digit

### Requirement

Write a program that determines the largest digit of a natural number read from the keyboard.

### Input data

The program will read a natural number from the keyboard.

### Output data

The program will display on the screen the largest digit of the read number.

### Restrictions and specifications

- the read number will be less than 2,000,000,000

### Example:

"Input"

```
2705
```

"Output"

```
7
```
