# Requirement

A natural number `n` is read. Calculate the sum of all natural numbers less than or equal to `n`.

# Input Data

The program reads the natural number `n` from the keyboard.

# Output Data

The program will display the number `S` on the screen, representing the sum of the numbers less than or equal to `n`.

# Constraints and Notes

- `n` ≤ 1,000,000

---

# Example

**Input**

```text
7
```

**Output**

```text
28
```

**Explanation**
1 + 2 + 3 + 4 + 5 + 6 + 7 = 28
